# Libre AI Schemas And Contracts

[English](README.md)

Les services qui échangent des données ont besoin d’une définition commune des messages valides et des évolutions compatibles. Ce projet explore des schémas et des exemples de référence pour les développeurs responsables de ces échanges, lorsque les applications et les langages évoluent à des rythmes différents.

## Usages visés

- Vérifier l’accord entre producteurs et consommateurs sur les données acceptées ou refusées.
- Décrire les changements compatibles entre deux versions d’un contrat d’échange.
- Comparer des représentations TypeScript et Rust à un schéma et des exemples communs.
